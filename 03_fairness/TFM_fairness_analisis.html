Anexo 3 - Análisis de equidad (fairness) y discriminación indirecta¶

Modelo evaluado: scorecard de comportamiento (WOE + regresión logística), el mismo champion que se despliega en la API y en el agente conversacional.

Cumplimiento: Directiva 2004/113/CE (prohibición del sexo como factor en el acceso a bienes y servicios) y principios de gestión de sesgo del AI Act para sistemas de scoring de crédito.

Qué se mide y por qué en este orden¶

  1. Coste predictivo de excluir la variable protegida SEX.
  2. Equidad del modelo que se despliega (la scorecard sin SEX): Disparate Impact y brechas de error por grupo. Esta es la medición relevante para un supervisor: no basta con demostrar que la exclusión es barata, hay que demostrar que el modelo que se pone en producción no genera impacto adverso.
  3. Sensibilidad al diseño muestral: el mismo cálculo repetido sobre cinco particiones, para saber si el veredicto depende de la semilla.
  4. Discriminación indirecta (proxy): correlación de cada variable con SEX y AUC de un modelo auxiliar que intenta reconstruir el sexo a partir de las variables del scorecard.

Notas metodológicas¶

  • El preprocesado, la semilla y la partición son idénticos al notebook principal (80/20 estratificado, RANDOM_SEED = 321, winsorización p1/p99 ajustada solo con train). Sin esa equivalencia las cifras de este anexo no serían comparables con las del Anexo 1.
  • La equidad se evalúa sobre la scorecard real, no sobre una regresión logística auxiliar estandarizada. Medir el sesgo de un modelo que no es el que se despliega produce cifras que no describen el sistema.
  • El resultado favorable para el cliente es no ser marcado como riesgo (prediccion = 0), y el umbral de decisión es el corte que se despliega (regla de Bayes con costes asimétricos, igual que en el Anexo 1). Como referencia se muestra también el DI con el corte neutro, la tasa de default de train.

def preparar(df, seed=RANDOM_SEED):
    """Split estratificado + winsorizacion ajustada SOLO con train."""
    tr, te = train_test_split(df, stratify=df["y"], test_size=TEST_SIZE, random_state=seed)

    return tr, te

3. Ajuste de la scorecard¶

Misma arquitectura que el champion: BinningProcess con tramificación óptima (tamaño mínimo de tramo 10 %, máximo cinco tramos, IV ≥ 0,02) y regresión logística sobre los valores WOE, escalada con el método PDO/odds.

Por qué el contrafactual necesita forzar la variable¶

Hay un detalle que condiciona todo el capítulo. El criterio de selección por Information Value descarta automáticamente las variables con IV < 0,02, y SEX queda por debajo de ese umbral. Es decir: aunque se le ofrezca al modelo, el proceso de tramificación la elimina por sí solo antes de que intervenga ningún criterio de cumplimiento.

Eso es un resultado interesante por sí mismo, pero invalida el contrafactual: si se ajustan los dos modelos con el filtro activo, salen idénticos y el "coste de excluir el sexo" mide exactamente cero, no porque la exclusión sea gratuita sino porque nunca llegó a incluirse.

Para que la comparación signifique algo, el contrafactual se ajusta eximiendo a SEX del filtro de IV (fixed_variables). Así se mide lo que de verdad interesa: qué ocurriría si una entidad decidiera usar la variable protegida.

def construir_binning(variables, categoricas, forzar=None):
    """BinningProcess del proyecto. 'forzar' exime a esas variables del filtro de IV."""
    kw = dict(
        min_bin_size=MIN_BIN_SIZE,
        max_n_bins=MAX_N_BINS,
        special_codes=None,
        categorical_variables=categoricas,
        variable_names=variables,
        selection_criteria={"iv": {"min": IV_MINIMO}},
    )
    if forzar:
        try:
            return BinningProcess(fixed_variables=forzar, **kw)
        except TypeError:
            # Versiones antiguas de optbinning no exponen fixed_variables:
            # se desactiva el filtro de IV para no perder la variable forzada.
            kw["selection_criteria"] = None
            return BinningProcess(**kw)
    return BinningProcess(**kw)


def ajustar_scorecard(df_tr, df_te, variables, categoricas, forzar=None):
    """Ajusta el champion como en el Anexo 1: quita de una en una las variables con
    coeficiente positivo (nunca las forzadas). Devuelve (modelo, PD sobre test)."""
    variables = list(variables)
    while True:
        modelo = Scorecard(
            binning_process=construir_binning(variables, [c for c in categoricas if c in variables], forzar),
            estimator=LogisticRegression(solver="lbfgs", penalty="l2", max_iter=1000),
            scaling_method="pdo_odds",
            scaling_method_params=PDO_PARAMS,
        )
        modelo.fit(df_tr[variables], df_tr["y"].values)
        coef = pd.Series(modelo.estimator_.coef_[0],
                         index=modelo.binning_process_.get_support(names=True))
        candidatas = coef.drop(labels=forzar or [], errors="ignore")
        if (candidatas <= 0).all():
            return modelo, modelo.predict_proba(df_te[variables])[:, 1]
        variables.remove(candidatas.idxmax())

4. Métricas de equidad¶

Se calculan tres familias, porque ninguna es suficiente por sí sola:

  • Disparate Impact (DI): cociente entre las tasas de resultado favorable de los dos grupos. Umbral de referencia 0,80 (four-fifths rule). Mide paridad demográfica: ignora si los grupos tienen distinto riesgo real.
  • Brecha de igualdad de oportunidad (ΔTPR): diferencia en la proporción de morosos correctamente detectados. Un modelo que detecta peor a un grupo le está concediendo crédito que no devolverá.
  • Brecha de falsos positivos (ΔFPR): diferencia en la proporción de clientes sanos penalizados. Es la métrica del perjuicio directo al cliente.

DI y ΔTPR no pueden optimizarse simultáneamente cuando la prevalencia difiere entre grupos (resultado de imposibilidad de Kleinberg et al., 2016); por eso se informan las tres y se documenta la elección, en lugar de presentar una sola cifra como certificado de equidad.

NOMBRE_GRUPO = {1: "Hombres", 2: "Mujeres"}


def metricas_equidad(y_true, pd_pred, grupo, umbral):
    """Devuelve (dict de metricas globales, DataFrame por grupo)."""
    y_true = np.asarray(y_true)
    pred   = (pd_pred >= umbral).astype(int)      # 1 = marcado como riesgo
    grupo  = np.asarray(grupo)

    filas = []
    for g in np.unique(grupo):
        m = grupo == g
        filas.append({
            "grupo":           NOMBRE_GRUPO.get(g, str(g)),
            "n":               int(m.sum()),
            "prevalencia":     y_true[m].mean(),                     # tasa real de impago
            "tasa_favorable":  (pred[m] == 0).mean(),                # no marcado como riesgo
            "TPR":             pred[m][y_true[m] == 1].mean(),       # morosos detectados
            "FPR":             pred[m][y_true[m] == 0].mean(),       # sanos penalizados
            "AUC":             roc_auc_score(y_true[m], pd_pred[m]),
            "PD_media":        pd_pred[m].mean(),
        })
    tabla = pd.DataFrame(filas)

    tasas = tabla["tasa_favorable"].values
    di = tasas.min() / tasas.max()
    desfavorecido = tabla.loc[tasas.argmin(), "grupo"]

    resumen = {
        "DI":                di,
        "grupo_desfavorecido": desfavorecido,
        "cumple_regla_80":   bool(di >= UMBRAL_DI),
        "delta_TPR":         tabla["TPR"].max() - tabla["TPR"].min(),
        "delta_FPR":         tabla["FPR"].max() - tabla["FPR"].min(),
        "delta_AUC":         tabla["AUC"].max() - tabla["AUC"].min(),
    }
    return resumen, tabla


def imprimir_equidad(titulo, resumen, tabla):
    print("=" * 78)
    print(titulo)
    print("=" * 78)
    print(tabla.round(4).to_string(index=False))
    marca = "CUMPLE" if resumen["cumple_regla_80"] else "NO CUMPLE"
    print(f"\nDisparate Impact : {resumen['DI']:.4f}  -> {marca} la regla del 80%")
    print(f"Grupo con menor tasa de resultado favorable: {resumen['grupo_desfavorecido']}")
    print(f"Brecha TPR (igualdad de oportunidad) : {resumen['delta_TPR']:.4f}")
    print(f"Brecha FPR (sanos penalizados)       : {resumen['delta_FPR']:.4f}")
    print(f"Brecha de AUC entre grupos           : {resumen['delta_AUC']:.4f}")

6. Sensibilidad del veredicto al diseño muestral¶

El Disparate Impact es un cociente entre dos proporciones estimadas sobre submuestras del test, de modo que arrastra error muestral. Antes de afirmar que un modelo "cumple la regla del 80 %" hay que comprobar si esa conclusión sobrevive a un cambio de partición.

Se repite el ciclo completo (split, winsorización, tramificación, ajuste y evaluación) sobre cinco semillas distintas. Si el DI cruzase el umbral de 0,80 en alguna de ellas, la conclusión no podría apoyarse en un único valor puntual.

7. Discriminación indirecta: variables proxy¶

Excluir SEX no elimina el riesgo de discriminación: otras variables pueden reproducir su información. Se cuantifica de dos formas complementarias.

  1. Correlación de cada variable del modelo con la variable protegida.
  2. AUC de un modelo auxiliar que intenta predecir el sexo a partir exclusivamente de las variables del scorecard. Un AUC de 0,5 significa que las variables no filtran ninguna información de sexo; por encima de 0,60 el riesgo proxy sería apreciable.

Este análisis estaba en el notebook principal en la versión anterior de la entrega. Se traslada aquí, que es el anexo al que corresponde por contenido.

# Modelo auxiliar: se puede reconstruir el sexo desde las variables del scorecard
from sklearn.impute import SimpleImputer
from sklearn.pipeline import make_pipeline


def auc_proxy(df_tr, df_te, variables):
    """AUC al intentar predecir el sexo con las variables del scorecard.

    Los NaN de las derivadas se imputan con la mediana y se anade un indicador de
    ausencia, porque el scorecard tambien usa la ausencia (tramo Missing).
    """
    m = make_pipeline(SimpleImputer(strategy="median", add_indicator=True),
                      StandardScaler(),
                      LogisticRegression(max_iter=1000))
    m.fit(df_tr[variables], (df_tr["SEX"] == 2).astype(int))
    return roc_auc_score((df_te["SEX"] == 2).astype(int),
                         m.predict_proba(df_te[variables])[:, 1])


auc_proxy_base = auc_proxy(df_train, df_test, VARS_MODELO)
